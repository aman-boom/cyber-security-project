# 🛡️ Cyber Security Project

## 📌 Project Overview

This is an advanced Cyber Security Project developed using Python and Flask. The project is designed to simulate and demonstrate multiple cyber security concepts through an interactive web interface.

The system includes features such as:

* Network Monitoring
* Attack Simulation
* Vulnerability Scanning
* Log Analysis
* Threat Detection
* User Activity Tracking
* Interactive Dashboard

This project is useful for educational purposes, cyber security demonstrations, and learning Flask-based web security applications.

# ⚙️ Features

## 🔍 Network Monitoring

Monitors network-related activities and displays results through the web interface.

## ⚠️ Attack Simulation

Simulates cyber attacks for educational and demonstration purposes.

## 🛡️ Vulnerability Scanning

Performs basic scanning operations to identify vulnerabilities.

## 📄 Log Analysis

Stores and analyzes logs generated by user activities and simulated attacks.

## 👤 User Management

Uses SQLite database to store user-related information securely.

## 📊 Dashboard Interface

Provides an interactive dashboard for better visualization of cyber security operations.

# 🖥️ Installation Guide

## Step 1: Clone Repository

```bash
git clone https://github.com/kunal-CODE-01/cyber-security-project.git
```

## Step 2: Open Project Folder

```bash
cd cyber-security-project
```

## Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

## Step 4: Run Application

```bash
python app.py
```
